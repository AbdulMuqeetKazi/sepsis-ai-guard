Design a production-level healthcare AI web application named “SepsisAI Guard”.

Project subtitle:
“Early Sepsis Risk Detection with Agentic AI Clinical Support”

The app is a clinical decision-support dashboard for sepsis risk prediction using machine learning and Gemini-powered AI explanations.

Design style:
- Modern healthcare SaaS dashboard
- Clean white background with soft light grey sections
- Medical blue primary color
- Teal/cyan secondary accent
- Green for Low Risk
- Yellow for Medium Risk
- Orange for High Risk
- Red for Critical Risk
- Rounded cards
- Subtle shadows
- Professional typography
- Minimal animations
- Responsive desktop-first layout
- Clean clinical interface, not cartoonish
- Should feel like a real AI hospital monitoring dashboard

Create these screens:

1. Landing Page
- Hero section with product name “SepsisAI Guard”
- Tagline: “Early Sepsis Risk Detection with Agentic AI Clinical Support”
- CTA buttons: “Get Started” and “Login”
- Feature cards:
  ML Sepsis Prediction
  Gemini Clinical Assistant
  Real-Time Alerts
  Patient History
  Doctor Feedback
  Model Performance
- Simple workflow section:
  Enter Vitals → ML Prediction → AI Explanation → Alert → Feedback
- Safety note:
  “Decision-support only. Final clinical decisions remain with qualified healthcare professionals.”

Overall UI requirements:
- Desktop dashboard layout

- Sidebar collapses on smaller screens
